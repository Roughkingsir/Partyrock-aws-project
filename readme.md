# Simple Scheduler with Amazon PartyRock

This project is a lightweight **scheduler prototype** built using **Amazon PartyRock**, designed to help users organize tasks or appointments in a simple, interactive way.

## 🧠 What I Learned

Through this experiment, I gained a better understanding of how to design effective prompts to guide AI behavior. Prompt clarity significantly improves the tool’s ability to understand and respond accurately.

## 🚀 What It Does

The scheduler allows users to:
- Add and manage basic tasks or events
- Use AI-generated suggestions for better planning
- Interact with a simple UI powered by a base model in PartyRock

## ⚠️ Limitations

PartyRock is a creative and user-friendly tool, but it has a few constraints:
- Only supports **base foundation models**
- No support for **external API calls**
- No **model fine-tuning**

For more advanced or production-level features (like enterprise use), consider exploring:
- **Amazon Q**
- **Amazon Bedrock**

## 💡 Why Use PartyRock?

Even with its limitations, PartyRock is:
- Great for quick prototyping
- Ideal for creative exploration
- A good introduction to working with foundation models

## 📌 Final Thoughts

This was a fun and insightful experiment into building with generative AI tools. PartyRock is a solid choice for rapid prototyping, experimentation, and learning.
